# HistoryJuno 项目概览

更新日期：2026-08-31

## 一句话定义

HistoryJuno 0.3.0 是注册到 HistoryVulcan/Aurora 的 Sub2API 账号与服务控制面板。

## 目标与边界

### 目标

- 在 Aurora 页面提供启动、代理连接、关闭和状态刷新操作。
- 默认展示 OpenAI OAuth 账号管理与 5h/7d 已用额度，并支持按分组、状态检索。
- 从 JSON 来源导入账号，选择目标分组，并自动绑定本机全局唯一代理 IP。
- 复用现有 Sub2API PowerShell 工具，不引入第二套服务实现。

### 范围

- HistoryVulcan 模块命令、Aurora 描述化页面和动作声明。
- 本机 Sub2API 管理登录、OpenAI OAuth 账号分页查询和批量额度只读查询。
- Sub2API 分组/代理查询、账号导入和导入后分组/代理写回。
- 本机 8080、9090、7890、17890 端口状态探测。

### 非目标

- 不重写 Sub2API 服务本体或代理内核。
- 不创建独立网页或自建 WPF 控件。

## 关键约束

- 平台或环境：Windows、PowerShell、.NET 8。
- 兼容性：HistoryVulcan 5.1.2，HistoryAurora 1.9.2；来源选择使用 sourcePicker，动态分组使用 optionsSource。
- 安全与权限：关闭动作由宿主确认；管理凭据只在内存中读取，不进入日志、命令结果或页面数据。
- 时间、成本或资源：不常驻后台线程，仅在点击动作或刷新时运行探测。
